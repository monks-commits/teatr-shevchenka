Вхід для співробітників

Доступ лише для співробітників (Supabase Auth).

Якщо не пускає
  1. Перевір, що /data/settings.json — валідний JSON і містить supabase_url та supabase_anon_key.
  2. Створи користувача в Supabase → Auth → Users (email+password).
  3. Застосуй SQL-політики (нижче), інакше таблиці можуть не читатись.
